# Склад App

Правила работы Codex и ChatGPT, команда «Го», точки входа и выпуск описаны в [AGENTS.md](AGENTS.md). Актуальную передачу незавершённых задач и проверенные состояния проекта смотри в [WORK_HANDOFF.md](WORK_HANDOFF.md).

Для быстрой проверки Основы на временной базе установите `backend/requirements.txt` в Python 3.12 и выполните `python scripts/smoke_warehouse.py`. Проверка обращается к маршрутам приложения без запуска фоновых задач Telegram.

После успешного релиза Railway GitHub Actions сохраняет `handoff.json` для передачи следующему чату. Сводка содержит SHA исходников, отпечаток сборки, время проверки и четыре результата `0` или `1` для `/health`, `/app/version`, `/` и `/pwa/`. Артефакты хранятся 30 дней. Тот же JSON доступен в аннотации `handoff.json` у проверки `handoff`, в том числе через API аннотаций GitHub Checks. Чтобы проверить текущий релиз вручную из нужного коммита, выполните `python3 scripts/release_handoff.py`.
