# Склад App

Правила работы Codex и ChatGPT, точки входа и выпуск описаны в [AGENTS.md](AGENTS.md).

Для быстрой проверки Основы на временной базе установите `backend/requirements.txt` в Python 3.12 и выполните `python scripts/smoke_warehouse.py`. Проверка обращается к маршрутам приложения без запуска фоновых задач Telegram.

После успешного релиза Railway GitHub Actions сохраняет `handoff.json` для передачи следующему чату. Сводка содержит SHA исходников, отпечаток сборки, время проверки и четыре результата `0` или `1` для `/health`, `/app/version`, `/` и `/pwa/`. Артефакты хранятся 30 дней. Чтобы проверить текущий релиз вручную из нужного коммита, выполните `python3 scripts/release_handoff.py`.
